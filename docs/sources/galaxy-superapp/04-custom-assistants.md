# Источники: пользовательские помощники

## GPTs как знакомый пример настройки помощника

OpenAI Help Center, [GPTs in ChatGPT](https://help.openai.com/en/articles/8554407-gpts-in-chatgpt).

Документация описывает GPTs как помощников для определённых целей, которые могут сочетать инструкции, загруженные знания, возможности, приложения или действия; помощника можно предварительно проверить. Это поддерживает знакомый пользователям ориентир для Galaxy: понятная карточка/настройка «роль + инструкции + знания + инструменты».

**Важно:** документация меняется. На дату проверки OpenAI Help Center содержит сообщение об изменениях и планах для custom GPTs в отдельных рабочих пространствах. Поэтому roadmap заимствует понятную пользовательскую модель, но не зависит от будущего продукта OpenAI и не предполагает копирования его ограничений или реализации.

## Что это означает для Galaxy

- Создание помощника начинается с понятного описания задачи, а не с технических полей.
- Пользователь выбирает, какие заметки/папки/проектные знания доступны помощнику.
- Подключённые инструменты и их права перечислены ясно.
- Перед сохранением можно испытать помощника на примерах.
- Изменения инструкций и знаний имеют версии; ошибочную версию можно отменить.
- Эффект помощника сравнивается с базовым вариантом на задачах; создание профиля само по себе не считается ценностью.
