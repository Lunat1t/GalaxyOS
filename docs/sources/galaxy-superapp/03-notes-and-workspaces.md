# Тема 3: рабочее пространство проекта

## Obsidian: Markdown-файлы и связи между заметками

- Официальная справка, [How Obsidian stores data](https://obsidian.md/help/Files%2Band%2Bfolders/How%2BObsidian%2Bstores%2Bdata): заметки хранятся как Markdown-файлы в папке vault.
- Официальная справка, [Link notes](https://obsidian.md/help/link-notes): заметки можно связывать, смотреть обратные ссылки и навигировать по сети знаний.

Roadmap использует Obsidian как понятный ориентир для комнаты-проекта с файлами, заметками и связями. Это не означает, что Galaxy должен копировать весь набор функций Obsidian или повторять его техническое устройство.

## Проектный контекст и история изменений

GitHub Docs, [About Projects](https://docs.github.com/en/issues/planning-and-tracking-with-projects/learning-about-projects/about-projects).

Проекты GitHub показывают знакомую разработчикам модель: задачи, таблицы/доски/roadmap views и поля с данными репозитория можно организовать в одном пространстве. Galaxy room отличается фокусом на контексте, заметках и LLM-помощниках; ссылка нужна как продуктовый reference для проектной организации, не как доказательство спроса.

## Переход из Galaxy в редактор кода

Microsoft, [Visual Studio Code: Command Line Interface](https://code.visualstudio.com/docs/configure/command-line).

Официальная документация VS Code описывает открытие папки проекта, файла и конкретной строки через CLI и URL-схему `vscode://`. Это подтверждает существование технического пути для выбранного варианта E: Galaxy может дать действие «открыть проект» или «перейти к найденному файлу/строке» в установленном редакторе.

**Ограничение:** это документация только VS Code. Она не доказывает, что все редакторы одинаково интегрируются, что такой переход бесшовен на каждой ОС или что пользователям нужен отдельный экран Galaxy. Поддержку редакторов и поведение открытия нужно проверить с пилотными разработчиками.

## Как это связано с другими частями Galaxy

Рабочее пространство отвечает на вопрос «где человек видит проект и продолжает работу». Оно не заменяет механизмы поиска и сборки контекста из [карточки 02](02-context-memory-agents.md) и не определяет само по себе, как устроены роли и память агентов из [карточки 04](04-custom-assistants.md).

## Гипотеза для Galaxy

Комната Galaxy должна быть единицей контекста разработки: кодовый репозиторий плюс Markdown-заметки, решения, инструкции, задачи, запуски агентов и проверки. Минимальная полезная версия не обязана включать визуальный граф, если дерево, поиск и обратные ссылки решают задачу проще.
