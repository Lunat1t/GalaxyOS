# Galaxy 3.1 alpha 1 — Living Graph

3.1 moves Galaxy from a static repository snapshot toward a project model that can notice change and reason about likely consequences.

## New capabilities

### World Drift

`WorldDriftReport` compares a stored snapshot with a fresh scan and produces evidence for file, symbol, edge and component changes. `world-drift` is read-only; `world-sync` updates the baseline while reporting the consumed drift.

### Future Graph

`FutureGraph` performs deterministic structural counterfactual propagation. A changed node is propagated across reverse dependency edges, while direct dependencies are included as lower-confidence review targets. The simulator reports blast radius, tests, docs, components, risk and limitations.

### Memory Reconciler

`MemoryReconciler` performs evidence-driven knowledge-health checks. It is dry-run by default. `--apply` changes lifecycle only for high-confidence rules. The design deliberately separates **detecting a contradiction** from **authorizing a state mutation**.

### Predictive Context Packets

The Context Compiler now embeds Future Graph impact plus knowledge-health findings. Agents can therefore see both relevant context and the current uncertainty around that context before execution.

## Safety / epistemic rules

- Future Graph is structural forecasting, not runtime certainty.
- Drift score measures amount of structural change, not whether a change is good or bad.
- Peer memory conflicts are never silently rewritten at low confidence.
- `brain-reconcile` defaults to dry-run.
- Existing Galaxy approval and deterministic verification layers remain authoritative.

## Tests

3.1 adds regression tests for:

- snapshot drift preview and consumption;
- symbol/file change detection;
- reverse dependency blast-radius propagation;
- context packet impact integration;
- repository source-hash invalidation;
- trusted same-slot assertion conflict handling.
