# GalaxyOS — Legacy Knowledge Archive

> Активная реализация старой Galaxy удалена из текущей ветки. Код не потерян: он остаётся в истории Git.

Этот репозиторий теперь служит архивом знаний проекта: эволюция концепции, архитектурные решения, эксперименты, результаты тестов, ошибки, ограничения и старые дорожные карты. Его задача — помочь следующей реализации Galaxy не повторять прежние ошибки.

## Что было Galaxy

Galaxy прошла путь от большой multi-agent системы с фиксированными ролями (Sun, Venera, Earth, Moon, Mercury, Mars, Ceres, Neptun) к слою контекста и памяти вокруг внешних coding-агентов: поиск релевантных файлов, Attention/Context Engine, память, evidence/provenance, world model и сборка компактного context package.

## Что было реально измерено

- На синтетическом наборе из 10 000 документов ускоренный поиск: 23 мс против 122 мс полного перебора; средний Recall@20 — 95,6%.
- На проекте из 152 файлов повторная сборка контекста: 20,8 мс с кэшем против 100,7 мс без кэша.
- Пилот из трёх SWE-bench задач не изменил исход. Выборка слишком мала, чтобы утверждать рост solve rate или экономию токенов end-to-end.

Это локальные измерения компонентов, а не доказательство качества продукта целиком.

## Правило для следующей Galaxy

Не переносить старую архитектуру целиком. Работать benchmark-first:

**baseline → измерение → минимальный механизм → повторное измерение.**

Отделять реализованное от гипотез и roadmap. Не путать microbenchmarks с end-to-end пользой.
