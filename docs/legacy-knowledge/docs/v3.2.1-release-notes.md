# Galaxy 3.2.1-alpha.2 — ContextBench

The internal historical Git benchmark from alpha.1 has been replaced with an adapter for the independent [ContextBench](https://github.com/EuniAI/ContextBench). See the README for setup and commands.

Galaxy retrieves files from the repository at the issue’s base commit using only the issue description. The external ContextBench package evaluates the JSONL predictions against its own human-annotated gold contexts. Galaxy reports file-level predictions only: its excerpts do not contain reliable line offsets, and no coding model runs to solve an issue.

The official dataset and evaluator must be installed separately, and repositories must be available locally with the required base commits. The command reports missing repositories or commits per instance and exits nonzero on partial failure.
