# Локальный MCP мост

Запустите клиент MCP из корня `galaxy/` с конфигурацией `system/mcp/mcp_config.json`. Нужен Node.js 18+.
Сервер предоставляет `get_note`, `append_log`, `search_vault`. По умолчанию работает внутри текущего vault; при необходимости задайте `VAULT_PATH` абсолютным путём к vault. Доступ к путям вне vault запрещён.

Это один локальный сервер. Роли агентов в `system/agents/` описывают рабочий процесс, но сами по себе не запускают агентов или проверки.
