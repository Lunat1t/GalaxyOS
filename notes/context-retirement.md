# Решение об отказе от контекстного ядра — 2026-10-06

Владелец Galaxy принял решение продолжать от исходников 3.2.1-alpha.19 как от основы локальной памяти. Разработка контекстного ядра исключена из текущего продукта. Это решение о границах проекта; оно не доказывает, что любой подход к контексту бесполезен.

## Что убрано

Из исполняемого кода удалены World Model, Future Graph и drift, Attention Engine и индекс репозитория, Context Compiler, capsules и кеш пакетов, Kernel Projector/Watcher, MCP get_context. Удалены их команды world-*, future-impact, attention-build, context-build, context-overview, kernel-observe, kernel-watch, mcp-server и соответствующие тесты. Старые названия команд отклоняются до запуска свободного запроса к модели.

## Что сохранено

BrainStore, MemoryStore, поиск по памяти, семантические сигналы, источники, подтверждение, исправление, отзыв и история; состояния active/stale/contradicted и MemoryReconciler; Markdown vault, ссылки, цели; ExperienceStore и доказательства выполнения alpha.19. В смешанных тестах сохранены проверки жизненного цикла памяти, reconciliation и решений.

ExperienceStore перенесён из galaxy_core/context/experience.py в galaxy_core/brain/experience.py. Формат и расположение SQLite данных сохранены. Поиск памяти и подготовка данных агента не требуют анализа файлов репозитория. Планирование и агенты остаются частью существующей alpha, но автоматически собирать пакеты исходников больше не будут.

Из более поздней локальной копии Galaxy сохранено небольшое улучшение происхождения памяти: явный source_ref для внешних источников, run:// для результатов запуска, manual://entry для ручных записей и legacy://unknown-origin для наследованных записей. Это обозначения происхождения, а не подтверждение достоверности. Большие зависимости новой платформы не переносились.

## Чтобы не повторить прежнее расширение

Следующие изменения должны улучшать сохранение, поиск, проверку или исправление знаний. Не возвращать анализ репозиториев, оптимизацию токенов coding-контекста, фоновый watcher, World Model или отдельную Core/OS платформу как обязательную часть памяти.

Возвращение этих направлений требует нового явного решения владельца с конкретной пользовательской задачей и критерием пользы. Архивные roadmap не являются поручениями к реализации. Число модулей, документов или опытов само по себе не показывает пользу памяти.

## Источники и ограничения

- Внутренние исходники этой папки: version 3.2.1-alpha.19-evidence-integrity; brain, vault, context/experience и engine/verification определили сохраняемые компоненты.
- Локальная копия Documents/Codex/galaxy-3.2.1-alpha.19-evidence-integrity: изменение MemoryStore.remember определило перенос правила provenance.
- [Архив legacy](archive/context/): планы и записи исследований скопированы из локального Amnesia/legacy-galaxy/docs для истории. Это прежние гипотезы и отчёты, а не доказательство результата нынешней сборки. Относительные ссылки внутри скопированных материалов могут ссылаться на файлы исходного legacy-репозитория.
- legacy-changelog и release notes сохранены как история. Прежний test-report находится в notes/reports/archive и не подтверждает проверку после удаления.
- Текущая рабочая папка не содержит доступной Git-истории. Здесь выполнено редактирование исходников alpha.19, а не Git reset или сравнение с последним remote GalaxyOS.

Документация сохраняется по прямому указанию владельца. Текущий scope описан в product-direction.md и core-architecture.md.

## Проверка после удаления

Локальная проверка: 79 тестов, 78 прошли, один пропущен. Дополнительно проверены повторное открытие ExperienceStore, фильтрация private-записей по переданному owner_id, изоляция проектов, отзыв, provenance и память агента без пакета исходников. Эти проверки не доказывают полноценную авторизацию пользователей.

Live LLM не запускался; mock HTTP server не смог открыть сокет в sandbox; полный chaos-набор был прерван после длительного ожидания. Эти ограничения отражены в [новом отчёте](reports/context-retirement-test-report.json).

## Новое начало версии

Текущая сборка называется Galaxy v1, версия пакета и CLI — 1.0.0. Прежняя нумерация сохранена только в исторических материалах. Документы и старые отчёты перенесены в notes/.
