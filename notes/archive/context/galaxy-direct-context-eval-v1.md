# Прямая проверка текущего контекста Galaxy — пилот

Дата анализа: 2026-10-04. Использован уже выполненный парный пилот
`reports/swebench-dataset-v1/sanity-pilot-v1/`: по одному запуску OFF и ON
на каждом из пяти заранее зафиксированных SWE-bench Verified задач.

## Вопрос

Помогает ли текущая передача контекста Galaxy решить те же coding-задачи
внешним Codex-исполнителем лучше, чем запуск без контекста Galaxy?

## Условия и результат

Одинаковые для обеих рук: модель `gpt-6-luna`, reasoning `low`, SWE-bench
Verified, версии/коммиты из замороженного манифеста. OFF — настоящий режим без
Galaxy context; ON — существующий ContextCompiler через compatibility adapter.
У каждой задачи ровно один официальный evaluator run на руку.

| Задача | OFF | ON | Входные+выходные токены OFF → ON | Время OFF → ON |
|---|---:|---:|---:|---:|
| matplotlib-13989 | прошла | прошла | 168,641 → 252,820 (+49.9%) | 195.2 → 214.0 с |
| django-13033 | прошла | прошла | 371,596 → 388,870 (+4.6%) | 166.7 → 160.9 с |
| sphinx-8548 | не прошла | не прошла | 494,640 → 432,801 (-12.5%) | 109.7 → 117.9 с |
| sympy-13878 | не прошла | не прошла | 358,733 → 1,025,635 (+185.9%) | 138.3 → 178.9 с |
| django-13406 | прошла | прошла | 235,481 → 369,043 (+56.7%) | 92.1 → 143.3 с |

Проверенный успех: **3/5 OFF и 3/5 ON; ни одна пара не изменила исход**.
Во всех пяти парах совпадает immutable base commit. Во всех десяти запусках
официальная проверка завершилась без инфраструктурного сбоя, evidence ledger
целостен; для каждого OFF/ON исхода хеш evaluator-отчёта совпадает.

Суммарные токены выросли с 1,629,091 до 2,469,169 (**+51.6%**). Медиана
парного изменения токенов — **+49.9%**; медианное время пары выросло примерно
на **9.6%**. Денежная стоимость не рассчитана: в конфигурации нет датированного
прайса. У этих показателей один запуск на руку, поэтому это ранний сигнал,
не стабильная оценка эффекта.

### Повторная сверка сохранённых артефактов

10 запусков повторно сверены с последними cumulative usage snapshots в
`events.jsonl` и официальными evaluator JSON. Все входные/выходные значения и
исходы совпали с `runs.jsonl`; SHA-256 всех 10 evaluator JSON совпал с
записанным хешем, все 10 evidence ledger помечены валидными. Раскладка
по usage traces: cached input — 1,465,856 OFF и 2,294,528 ON; uncached input —
154,793 OFF и 162,552 ON; output — 8,442 OFF и 12,089 ON. Из роста суммарных
токенов +840,078: +828,672 пришлись на cached input, +7,759 на uncached input
и +3,647 на output. Это счётчики обработки, не расчёт денег: без датированного
тарифа денежный эффект неизвестен. Подробная запись сверки с хешами — в
[`paired-audit.json`](../reports/swebench-dataset-v1/sanity-pilot-v1/paired-audit.json).

Пересборка trajectory-отчёта пометила старые значения `context_tokens` для
пяти ON запусков как недоступные: они были получены из Markdown-символов / 4,
а исходной оценки ContextPackage в этих legacy runs нет. Это не меняет
evaluator outcomes и usage totals, но старую оценку размера контекста нельзя
считать точной.

## Вывод

На этих пяти задачах текущая передача Galaxy context не повысила проверенный
успех; в этом малом наборе агент израсходовал больше токенов и чаще тратил
больше времени. Возможный потолок на лёгких задачах, стохастичность модели,
низкий reasoning и малый размер выборки не позволяют заключить, что Galaxy
в целом бесполезна. Эти данные также ничего не говорят о переносе Experience:
прошлый опыт в данном OFF/ON сравнении не испытывался.

Это уже прямой ответ на базовый вопрос текущего Context пути. Следующий
полезный шаг — заранее зафиксированная повторная OFF/ON оценка на большем
разнообразном наборе accepted задач и повторениях на задачу. Основная метрика —
verified success; токены и время — вторичные. До появления улучшения на прямом
измерении не приписывать выгоду Galaxy Context и не усложнять эксперимент
переносом эпизодов. Не объявлять неудачную задачу источником Experience.
