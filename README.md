# Galaxy

**Galaxy помогает coding-агентам работать с контекстом проекта.** Он находит нужные файлы и проектные знания, собирает из них короткую подборку и может передать её llm.

> Сейчас Galaxy — локальный инструмент в разработке. Это ещё не готовый плагин, облачный сервис или приложение с комнатами.

## Быстрый старт

Из корня репозитория:

```bash
python galaxy.py --help
python galaxy.py doctor
python codex_context.py build "исправить обновление токена" --root .
```

Последняя команда собирает контекст в JSON. Проверьте результат и передайте его Codex вместе с задачей.

Для Obsidian есть отдельный локальный MCP-мост с инструментами для заметок. Он не подключает Galaxy к Codex автоматически: [инструкция по MCP](system/mcp/README.md).

## Что делает Galaxy

1. Изучает структуру проекта.
2. Ищет файлы, инструкции и сохранённые знания, подходящие к задаче.
3. Собирает контекст с указанием источников.
4. Передаёт его coding-агенту для работы.

Galaxy помогает найти нужную информацию, но сам по себе не гарантирует правильный результат.

## Что уже проверяли

- На синтетическом наборе из 10 000 документов ускоренный поиск занял 23 мс против 122 мс при полном переборе. Средний Recall@20 — 95,6%.
- На проекте из 152 файлов повторная сборка контекста с кэшем заняла 20,8 мс против 100,7 мс без кэша.
- В пилоте из трёх SWE-bench задач Galaxy не изменил исход. Выборка слишком мала для вывода о качестве решений или экономии токенов.

Это локальные замеры компонентов Galaxy, а не доказательство, что coding-агент решает задачи лучше. Подробности и ограничения: [оценка продукта](docs/sources/galaxy-superapp/05-product-validation.md).
