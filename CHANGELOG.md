# Изменения Galaxy

Все новые шаги пересборки Galaxy Code записываются здесь по версиям. Запись кратко отвечает: что изменилось, зачем и что реально работает.

## v1.0.5 — 2026-10-08

**Этап 1, шаг 1: реестр проектов.**

- Добавлены команды `galaxy project add`, `open` и `list`; список проектов и последний открытый проект сохраняются отдельно от каталога программы.
- Это основа для запуска Galaxy из любого каталога и будущего TUI.
- Номер пакета и CLI повышен до `1.0.5`.

**Состояние:** TUI и выполнение задач с учётом активного проекта ещё не подключены.

## v1.0.4 — 2026-10-08

**Этап 0 завершён:** описан путь задачи от запроса до решения по diff и формат журнала Run.

- Зафиксированы ключевые события: запуск, сообщения, инструменты, проверки, diff, решение и завершение.
- Переход к этапу 1: Project и основной TUI.
- Номер пакета и CLI повышен до `1.0.4`.

**Состояние:** этап 0 — документация; новый интерфейс и цикл исполнения ещё не реализованы.

## v1.0.3 — 2026-10-08

**Этап 0, шаг 3: инвентаризация и миграция.**

- Составлена карта памяти, vault, опыта, агентов, запусков, проверок, интервью и конфигурации с путями и форматами.
- Зафиксировано, что старый мигратор переносит только часть данных; описаны резервное копирование, сверка и откат.
- Номер пакета и CLI повышен до `1.0.3`.

**Состояние:** составлен план; данные не переносились.

## v1.0.2 — 2026-10-08

**Этап 0, шаг 2: логическая модель данных.**

- Описаны Project, Agent, Task, Run, Worker, Approval, события, проверки, провайдеры, инструменты и ссылки на память; указаны владельцы данных и жизненные циклы.
- Зафиксировано разделение постоянной личности Agent и отдельных запусков, проверок и решений пользователя.
- Номер пакета и CLI повышен до `1.0.2`.

**Состояние:** это архитектурная схема; формат хранения и миграция ещё не выбраны.

## v1.0.1 — 2026-10-08

**Этап 0, шаг 1: направление архитектуры.**

- Обновлены инструкции и действующие документы: Galaxy Code стал целью разработки, выбран TUI «Рабочая область» и первый локальный цикл с Codex.
- Закреплены сохранность памяти и данных, явное подтверждение diff и границы нового Context Builder.
- Номер пакета и CLI повышен до `1.0.1`, чтобы этот шаг можно было однозначно отличить от исходной `1.0.0`.

**Состояние:** новый TUI и агентный цикл ещё не реализованы; работает прежняя локальная память.
