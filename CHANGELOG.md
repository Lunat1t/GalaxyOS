# Изменения Galaxy

Все новые шаги пересборки Galaxy Code записываются здесь по версиям. Запись кратко отвечает: что изменилось, зачем и что реально работает.

## v1.1.8 — 2026-10-08

**Этап 1: единый запуск веб-Workspace.**

- `npm run dev:galaxy` запускает локальный API и Next.js; `Ctrl+C` останавливает оба процесса.
- Адрес и порты ограничены localhost и настраиваются переменными окружения.
- Обновлены инструкции, архитектура и правила разработки: веб-приложение — главный интерфейс.

**Проверка:** общий запуск, страница, API и остановка прошли. После перезапуска сохранились проект, настройка провайдера и задача. Проверка выполнена на временной базе; агент ещё не подключён.

## v1.1.7 — 2026-10-08

**Этап 1: настройки Workspace.**

- Добавлен экран настройки провайдера проекта; значение сохраняется через локальный API.
- На телефоне можно переключать проекты и добавлять папки.
- Сборка Next.js прошла; провайдер пока не запускается.

## v1.1.6 — 2026-10-08

**Этап 1: первый Next.js Workspace.**

- Добавлено веб-превью: выбор и регистрация проектов, список задач и сохранение запросов через локальный API.
- Токен API остаётся на серверной стороне Next.js; интерфейс явно показывает, что агент ещё не запускается.
- Производственная сборка Next.js прошла.

**Состояние:** проекты и очередь доступны в браузере; настройки, Run, проверки и diff ещё впереди.

## v1.1.5 — 2026-10-08

**Этап 1: первый локальный API.**

- Добавлена команда `galaxy serve` и API проектов, настроек и очереди задач для будущего веб-клиента.
- Сервис слушает только localhost и требует временный токен для запросов.
- После `1.0.9` нумерация продолжена как `1.1.0`; прежние записи ниже приведены к этой схеме.

**Состояние:** API доступен отдельно; Next.js ещё не подключён.

## v1.1.4 — 2026-10-08

**Этап 1: контракт локального API.**

- Описано, как Next.js будет обращаться к Python-ядру через локальный сервис.
- Зафиксированы первые операции проектов/задач и границы безопасности; Run-события добавятся вместе с исполнителем.
- Это спецификация: HTTP-сервис и веб-клиент пока не созданы.

## v1.1.3 — 2026-10-08

**Уточнено направление интерфейса.**

- Главным интерфейсом Galaxy Code станет веб-приложение на Next.js; CLI/TUI остаются переходными инструментами.
- Для мобильной версии предусмотрен отдельный интерфейс поверх общей логики; мобильный фреймворк пока не выбран.
- Следующий архитектурный шаг — описать локальный API между веб-клиентом и Python-ядром.

**Состояние:** это решение и обновление плана; веб-приложение ещё не создано.

## v1.1.2 — 2026-10-08

**Этап 1, шаг 2: узкий Workspace.**

- На узком терминале Workspace показывает одну область за раз; Tab переключает разделы, основные команды остаются доступны.
- Это сохраняет доступ к проектам и очереди без широкого окна.
- Номер CLI и пакета повышен до `1.1.2`.

**Состояние:** узкий экран реализован; запуск агента ещё не подключён.

## v1.1.1 — 2026-10-08

**Этап 1, шаг 2: основной Workspace.**

- На главном экране задачи проекта видны рядом со списком проектов; справа показаны путь, ветка и исполнитель.
- Новая задача по-прежнему сохраняется в очередь выбранного проекта, без запуска агента.
- Номер CLI и пакета повышен до `1.1.1`.

**Состояние:** экран ближе к макету; диалог, события Run, проверки и diff появятся в следующих шагах.

## v1.1.0 — 2026-10-08

**Этап 1, шаг 4: установка.**

- Добавлены команды установки для Linux/macOS и Windows; на Windows терминальная поддержка ставится как зависимость.
- Обновление позволяет установить `galaxy` как пользовательскую команду и открывать Workspace из разных каталогов.
- Проверена только локальная конфигурация пакета; установка на трёх ОС отдельно не запускалась.

**Состояние:** команда установки описана; межплатформенная проверка остаётся.

## v1.0.9 — 2026-10-08

**Этап 1, шаг 2: очередь задач проекта.**

- В Workspace можно сохранять запросы и видеть их статус `queued`; добавлены команды `project task-add` и `project tasks`.
- Это даёт проекту постоянный список работы до подключения агента.
- Номер пакета и CLI повышен до `1.0.9`.

**Состояние:** задачи хранятся локально; агент их пока не запускает.

## v1.0.8 — 2026-10-08

**Этап 1, шаг 3: разделы Workspace.**

- Клавиша Tab переключает экраны проекта, агентов, моделей, Skills/MCP, разрешений и настроек.
- Не подключённые функции прямо отмечены в интерфейсе; он показывает текущие сохранённые настройки.
- Номер пакета и CLI повышен до `1.0.8`.

**Состояние:** экраны справочные; настройки пока не управляют запуском агента и инструментов.

## v1.0.7 — 2026-10-08

**Этап 1, шаг 3: просмотр и настройки проекта.**

- Добавлены команды просмотра проекта и чтения/сохранения его настроек; в TUI есть экран настроек.
- Galaxy проверяет провайдера и формат списков Skills, MCP и разрешений; отдельного поля для credentials нет.
- Номер пакета и CLI повышен до `1.0.7`.

**Состояние:** настройки сохраняются; разделы интерфейса добавлены в v1.0.8.

## v1.0.6 — 2026-10-08

**Этап 1, шаг 2: TUI выбора проекта.**

- Запуск `galaxy` без команды открывает Workspace с недавними проектами, путём и Git-веткой.
- Можно открыть или добавить каталог; для терминалов без curses есть построчный режим.
- Номер пакета и CLI повышен до `1.0.6`.

**Состояние:** выбор проекта работает; экран настроек добавлен в v1.0.7.

## v1.0.5 — 2026-10-08

**Этап 1, шаг 1: реестр проектов.**

- Это основа для запуска Galaxy из любого каталога и будущего TUI.
- Номер пакета и CLI повышен до `1.0.5`.

**Состояние:** реестр проектов и CLI-команды готовы; основной TUI добавлен в v1.0.6.
