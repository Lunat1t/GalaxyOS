# Galaxy: инструкции разработки

Действующее решение владельца от 2026-10-08: пересобрать Galaxy v1 в Galaxy Code по плану в `/home/bah/Downloads/Galaxy_Code_Detailed.md`, раздел 48. Работать по этапам, сообщать владельцу о сделанном и объяснять назначение изменений. Текущий исполняемый код остаётся локальной памятью Galaxy v1 до реализации и проверки новых этапов; не выдавать план за готовый продукт. Каждый завершённый шаг оформляй новой версией и короткой понятной записью в едином `CHANGELOG.md`.

Перед архитектурными изменениями прочитай `notes/product-direction.md`, `notes/core-architecture.md` и `notes/context-retirement.md`. Первый рабочий срез: локальный проект, выбранный TUI «Рабочая область», один агент, Codex CLI, журнал работы, проверки, Git diff и решение пользователя о применении изменений. Другие провайдеры первой версии: OpenRouter, `agy` (Antigravity CLI), Claude Code. Серверный Qwen — позднее.

Сохраняй память, Markdown vault, цели, опыт, provenance, историю исправлений и существующие пользовательские данные. Семантический поиск памяти разрешён. Постоянный Agent имеет устойчивую идентичность и память; временный Worker ограничен одной задачей. Смена провайдера не меняет идентичность Agent. Права, стоимость и фоновые запуски должны быть явными.

Новое решение разрешает проектировать ограниченный Context Builder для конкретной задачи: выбирать релевантные файлы, правила, результаты проверок и записи памяти с указанием источников. Оно не возвращает прежние World Model, Attention Engine, Context Compiler, watcher/projector, оптимизацию всего coding-контекста или Core/OS платформу. `notes/context-retirement.md` и архив сохраняют историю прежнего решения.

Исторические release notes, CHANGELOG и `notes/archive/context` сохраняются для анализа прежнего пути. Планы из архива не являются действующими инструкциями. Не удаляй историческую документацию в рамках чистки кода.

Не утверждай успех по старым отчётам. Проверяй затронутые функции локально; внешние модели и платные provider calls не нужны для проверки памяти.
