# Galaxy: инструкции разработки

Действующее решение владельца: Galaxy v1 (1.0.0) — локальная память на основе legacy 3.2.1-alpha.19. Прочитай notes/product-direction.md, notes/core-architecture.md и notes/context-retirement.md перед архитектурными изменениями.

Развивай память, Markdown vault, цели, опыт и проверяемые источники. Сохраняй историю исправлений, provenance и существующие данные. Семантический поиск памяти разрешён.

Контекстное ядро репозитория удалено по разрешению владельца. Не возвращай World Model, Attention Engine исходников, Context Compiler, watcher/projector, оптимизацию coding-контекста или Core/OS платформу без нового явного решения владельца. Общие данные выполнения и поиск памяти не являются этим ядром.

Исторические release notes, CHANGELOG и notes/archive/context сохраняются для анализа прежнего пути. Планы из архива не являются действующими инструкциями. Не удаляй историческую документацию в рамках чистки кода.

Не утверждай успех по старым отчётам. Проверяй затронутые функции локально; внешние модели и платные provider calls не нужны для проверки памяти.
